# MealCoin — Indexer & RPC Spec

**Covers tickets:** IDX-01 through IDX-08
**Location in repo:** `/indexer/`
**Runtime:** Node.js 20 · TypeScript · viem · @supabase/supabase-js

---

## Overview

The indexer is a standalone long-running Node.js process that:

1. Polls Base Sepolia every 5 seconds for new blocks
2. Fetches logs from two contracts: **MealSwipeToken** and **Marketplace**
3. Decodes each event and writes the result to Supabase
4. Persists the last processed block to disk so restarts don't re-process old events

It is the **sole writer** to the `offers`, `trades`, and `redemptions` tables. The Next.js API layer only reads from those tables.

## Schema Note — `offers.offer_id` and `contract_address`

The DB schema defines `offer_id` as UUID (auto-generated by Postgres). The Marketplace contract emits `offerId` as `uint256` (1, 2, 3...). These are different types.

**Resolution:** The `offers` table has an `onchain_offer_id BIGINT` column plus a `contract_address TEXT` column. The indexer upserts on the compound key `(onchain_offer_id, contract_address)`. Postgres generates the UUID `offer_id`. The `trades` table FK references `offers.offer_id` (UUID).

Scoping to `contract_address` prevents cross-deployment ID collisions: when the Marketplace is redeployed and offer IDs restart from 1, the new contract address forms a different compound key, so a fresh INSERT (with a new `created_at`) is issued instead of an UPDATE that would preserve the old timestamp.

**Migration to run in Supabase SQL editor:**
```sql
ALTER TABLE offers ADD COLUMN IF NOT EXISTS onchain_offer_id BIGINT;
ALTER TABLE offers ADD COLUMN IF NOT EXISTS contract_address TEXT;

-- Backfill existing rows with the old contract address
UPDATE offers SET contract_address = '0x57dddf695b5cf4ef57f1c9b1aabd9b6f45430343' WHERE contract_address IS NULL;

ALTER TABLE offers ALTER COLUMN contract_address SET NOT NULL;

-- Drop old single-column constraint and add compound one
ALTER TABLE offers DROP CONSTRAINT IF EXISTS offers_onchain_offer_id_key;
ALTER TABLE offers ADD CONSTRAINT offers_onchain_offer_id_contract_address_key
  UNIQUE (onchain_offer_id, contract_address);

CREATE INDEX IF NOT EXISTS idx_offers_onchain_id ON offers (onchain_offer_id);
```

```ts
import * as fs from 'fs'
const STATE_FILE = '.lastblock'

export function loadLastBlock(): bigint | null {
  try {
    const raw = fs.readFileSync(STATE_FILE, 'utf8').trim()
    return raw ? BigInt(raw) : null
  } catch {
    return null
  }
}

export function saveLastBlock(block: bigint): void {
  fs.writeFileSync(STATE_FILE, block.toString())
}
```

### `src/retry.ts`
```ts
export async function withRetry<T>(
  fn: () => Promise<T>,
  maxAttempts = 5,
  label = 'operation'
): Promise<T> {
  for (let attempt = 1; attempt <= maxAttempts; attempt++) {
    try {
      return await fn()
    } catch (err) {
      if (attempt === maxAttempts) {
        console.error(`[ERROR] ${label} failed after ${maxAttempts} attempts:`, err)
        throw err
      }
      const delay = Math.pow(2, attempt - 1) * 1000  // 1s, 2s, 4s, 8s, 16s
      console.warn(`[WARN] ${label} attempt ${attempt} failed. Retrying in ${delay}ms...`)
      await sleep(delay)
    }
  }
  throw new Error('unreachable')
}

export const sleep = (ms: number) => new Promise(resolve => setTimeout(resolve, ms))
```

### `src/index.ts`
```ts
import { config } from './config'
import { loadLastBlock, saveLastBlock } from './state'
import { pollOnce } from './poller'
import { sleep } from './retry'
import { createPublicClient, http } from 'viem'
import { baseSepolia } from 'viem/chains'

const client = createPublicClient({
  chain: baseSepolia,
  transport: http(config.rpcUrl),
})

async function main() {
  console.log('[INFO] MealCoin indexer starting...')

  while (true) {
    try {
      const latestBlock = await client.getBlockNumber()
      const fromBlock = (loadLastBlock() ?? latestBlock - 1n) + 1n

      if (fromBlock > latestBlock) {
        await sleep(config.pollInterval)
        continue
      }

      // Warn on large gap
      if (latestBlock - fromBlock > 200n) {
        console.warn(`[WARN] Gap detected: ${latestBlock - fromBlock} blocks behind`)
      }

      // Process in chunks
      for (let start = fromBlock; start <= latestBlock; start += BigInt(config.chunkSize)) {
        const end = start + BigInt(config.chunkSize) - 1n < latestBlock
          ? start + BigInt(config.chunkSize) - 1n
          : latestBlock

        const ts = new Date().toISOString()
        console.log(`[${ts}] Polling block ${start} to ${end}`)

        await pollOnce(client, start, end)
        saveLastBlock(end)
      }
    } catch (err) {
      console.error('[ERROR] Poll loop error:', err)
    }

    await sleep(config.pollInterval)
  }
}

main()
```

### `src/poller.ts`
```ts
import { type PublicClient, parseAbiItem } from 'viem'
import { config } from './config'
import { withRetry } from './retry'
import { MARKETPLACE_ABI } from '../abis/marketplace'
import { TOKEN_ABI } from '../abis/token'
import { handleOfferCreated } from './handlers/offerCreated'
import { handleOfferAccepted } from './handlers/offerAccepted'
import { handleOfferCancelled } from './handlers/offerCancelled'
import { handleOfferExpired } from './handlers/offerExpired'
import { handleSwipeRedeemed } from './handlers/swipeRedeemed'
import { handleSwipesBurned } from './handlers/swipesBurned'

export async function pollOnce(
  client: PublicClient,
  fromBlock: bigint,
  toBlock: bigint
): Promise<void> {
  // Fetch logs from both contracts in parallel
  const [marketLogs, tokenLogs] = await Promise.all([
    withRetry(
      () => client.getLogs({ address: config.marketAddress, fromBlock, toBlock, abi: MARKETPLACE_ABI }),
      5, 'marketplace getLogs'
    ),
    withRetry(
      () => client.getLogs({ address: config.tokenAddress, fromBlock, toBlock, abi: TOKEN_ABI }),
      5, 'token getLogs'
    ),
  ])

  // Merge and sort by block + log index
  const allLogs = [...marketLogs, ...tokenLogs].sort((a, b) =>
    a.blockNumber === b.blockNumber
      ? Number(a.logIndex) - Number(b.logIndex)
      : Number(a.blockNumber) - Number(b.blockNumber)
  )

  let eventCount = 0
  for (const log of allLogs) {
    try {
      switch (log.eventName) {
        case 'OfferCreated':   await handleOfferCreated(log);   break
        case 'OfferAccepted':  await handleOfferAccepted(log);  break
        case 'OfferCancelled': await handleOfferCancelled(log); break
        case 'OfferExpired':   await handleOfferExpired(log);   break
        case 'SwipeRedeemed':  await handleSwipeRedeemed(log);  break
        case 'SwipesBurned':   await handleSwipesBurned(log);   break
      }
      eventCount++
    } catch (err) {
      console.error(`[ERROR] Failed to handle ${log.eventName} in tx ${log.transactionHash}:`, err)
    }
  }

  if (eventCount > 0) {
    console.log(`[INFO] Processed ${eventCount} events`)
  }
}
```

## IDX-03 — Parse & Store OfferCreated Events

**Event signature:**
```
OfferCreated(uint256 indexed offerId, address indexed creator, uint8 offerType, uint256 swipeCount, uint256 pricePerSwipe, uint256 expiresAt)
```

**`offerType` enum:** `0 = Ask (sell)`, `1 = Bid (buy)`

### `src/handlers/offerCreated.ts`
```ts
import { db } from '../db'
import { config } from '../config'
import { withRetry } from '../retry'

export async function handleOfferCreated(log: any): Promise<void> {
  const { offerId, creator, offerType, swipeCount, pricePerSwipe, expiresAt } = log.args

  const type = offerType === 0 ? 'ask' : 'bid'
  const priceDecimal = Number(pricePerSwipe) / 1_000_000  // MockUSDC 6 decimals → dollars

  console.log(`[OfferCreated] offerId=${offerId} type=${type} creator=${creator} price=$${priceDecimal}`)

  await withRetry(() =>
    db.upsertOffer({
      onchain_offer_id: Number(offerId),
      contract_address: config.marketAddress.toLowerCase(),
      type,
      seller_address: creator.toLowerCase(),
      swipe_count: Number(swipeCount),
      price_per_swipe: priceDecimal,
      status: 'pending',
      tx_hash: log.transactionHash,
      expires_at: new Date(Number(expiresAt) * 1000).toISOString(),
    }),
    2, 'upsert offer'
  )
}
```

**DB upsert:** `ON CONFLICT (onchain_offer_id, contract_address) DO UPDATE SET ...` — compound key prevents cross-deployment collisions.

## IDX-04 — Parse & Store OfferAccepted and OfferCancelled Events

### OfferAccepted

**Event signature:**
```
OfferAccepted(uint256 indexed offerId, address indexed acceptor)
```

The handler needs to look up the offer from DB to get `seller_address`, `swipe_count`, and `price_per_swipe` for the trade row.

```ts
// src/handlers/offerAccepted.ts
import { config } from '../config'

export async function handleOfferAccepted(log: any): Promise<void> {
  const { offerId, acceptor } = log.args

  console.log(`[OfferAccepted] offerId=${offerId} acceptor=${acceptor}`)

  // 1. Look up the offer to get creator + price details
  const offer = await db.getOfferByOnchainId(Number(offerId), config.marketAddress.toLowerCase())
  if (!offer) {
    console.warn(`[WARN] OfferAccepted: no DB row for onchain_offer_id=${offerId}`)
    return
  }

  // 2. Update offer status
  await withRetry(() =>
    db.updateOfferStatus(offer.offer_id, 'accepted'),
    2, 'update offer accepted'
  )

  // 3. Insert trade row
  await withRetry(() =>
    db.insertTrade({
      offer_id: offer.offer_id,
      buyer_address: acceptor.toLowerCase(),
      seller_address: offer.seller_address,
      swipe_count: offer.swipe_count,
      price: offer.swipe_count * offer.price_per_swipe,
      tx_hash: log.transactionHash,
    }),
    2, 'insert trade'
  )
}
```

## `src/db.ts` — Supabase Client & Write Functions

```ts
import { createClient } from '@supabase/supabase-js'
import { config } from './config'

const supabase = createClient(config.supabaseUrl, config.supabaseKey)

export const db = {

  async upsertOffer(row: {
    onchain_offer_id: number
    contract_address: string        // lowercase Marketplace address
    type: 'ask' | 'bid'
    seller_address: string
    swipe_count: number
    price_per_swipe: number
    status: string
    tx_hash: string
    expires_at: string
  }) {
    const { error } = await supabase
      .from('offers')
      .upsert(row, { onConflict: 'onchain_offer_id,contract_address' })
    if (error) throw new Error(`upsertOffer: ${error.message}`)
  },

  async getOfferByOnchainId(onchainOfferId: number, contractAddress: string) {
    const { data, error } = await supabase
      .from('offers')
      .select('offer_id, seller_address, swipe_count, price_per_swipe')
      .eq('onchain_offer_id', onchainOfferId)
      .eq('contract_address', contractAddress)
      .maybeSingle()
    if (error) throw new Error(`getOfferByOnchainId: ${error.message}`)
    return data
  },

  async updateOfferStatus(offerId: string, status: 'accepted' | 'cancelled' | 'expired') {
    const { error } = await supabase
      .from('offers')
      .update({ status })
      .eq('offer_id', offerId)
    if (error) throw new Error(`updateOfferStatus: ${error.message}`)
  },

  async insertTrade(row: {
    offer_id: string
    buyer_address: string
    seller_address: string
    swipe_count: number
    price: number
    tx_hash: string
  }) {
    const { error } = await supabase
      .from('trades')
      .upsert(row, { onConflict: 'tx_hash' })
    if (error) throw new Error(`insertTrade: ${error.message}`)
  },

  async upsertRedemption(row: { wallet_address: string; tx_hash: string }) {
    const { error } = await supabase
      .from('redemptions')
      .upsert(row, { onConflict: 'tx_hash' })
    if (error) throw new Error(`upsertRedemption: ${error.message}`)
  },

  async expireAllPendingOffers(): Promise<number> {
    const { data, error } = await supabase
      .from('offers')
      .update({ status: 'expired' })
      .eq('status', 'pending')
      .select('offer_id')
    if (error) throw new Error(`expireAllPendingOffers: ${error.message}`)
    return data?.length ?? 0
  },
}
```

## IDX-07 — Reliability: Retry Logic & Gap Detection

Already integrated throughout the design above. Summary:

| Concern | Implementation |
|---|---|
| RPC failure | `withRetry(fn, 5)` — exponential backoff 1s/2s/4s/8s/16s |
| DB write failure | `withRetry(fn, 2)` — one retry before logging error |
| Gap detection | Warn log if `latestBlock - fromBlock > 200` at poll start |
| Per-event error isolation | Each event handler wrapped in try/catch — one bad event never kills the loop |
| Loop never exits | Top-level `while(true)` with outer try/catch — all errors are logged, not thrown |
| State persistence | `saveLastBlock(end)` after each chunk succeeds |

|---|---|---|---|
| `OfferCreated` | Marketplace | offerCreated | `offers` upsert (status=pending) |
| `OfferAccepted` | Marketplace | offerAccepted | `offers` update (status=accepted) + `trades` insert |
| `OfferCancelled` | Marketplace | offerCancelled | `offers` update (status=cancelled) |

| `SwipeRedeemed` | MealSwipeToken | swipeRedeemed | `redemptions` upsert |
| `SwipesBurned` | MealSwipeToken | swipesBurned | `offers` bulk update (all pending → expired) |

## Key Data Conversions

| Data | On-chain format | DB format |
|---|---|---|
